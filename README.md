# HandWare

**HandWare** is a WarioWare-inspired microgame collection where your hands are the main characters. Control two independent hands, each with its own click, and complete fast, chaotic, and ridiculous challenges before time runs out.

Each hand works independently and can interact with the world using its own controls. You will have to coordinate both hands to complete tasks such as:

- Breaking.
- Solving.
- Cleaning.
- Cutting.
- Dodging.
  ...

# Setup

To setup this project you can clone this repository and open it with [godot](https://godotengine.org/es/).
Or you can download the build from releases and play it directly
