# HandWare

**HandWare** is a WarioWare-inspired microgame collection where your hands are the main characters. Control two independent hands, each with its own click, and complete fast, chaotic, and ridiculous challenges before time runs out.

<img width="1055" height="516" alt="Sin título" src="https://github.com/user-attachments/assets/9707ad83-047b-4256-ad13-b3d29160e056" />

Each hand works independently and can interact with the world using its own controls. You will have to coordinate both hands to complete tasks such as:

- Breaking.
- Solving.
- Cleaning.
- Cutting.
- Dodging.
- Operating.
  ...

---

# 🕹️ Features

## Dynamic Difficulty System

The game gets harder as you progress:

- Faster gameplay.
- Less time.
- More pressure.
- New challenges.

The further you go, the more chaotic it becomes.

## Unlockables

Earn high scores to unlock:

- New microgames.
- New hand skins.

---

# 🏆 Goal

Get the highest score possible by completing as many microgames as you can.
